# Reframe It – Capstone Project

## Overview
This is my Savvy Coders Capstone project. I started with the class boilerplate and turned it into a single-page app built around tarot and affirmations.

The idea is simple:
- Draw a tarot card from a local JSON deck
- Get a daily affirmation from an API (using a CORS proxy)
- Put them together to help reframe thoughts and shift perspective

It’s built with **Parcel**, **Navigo** for routing, and my own custom CSS.

## Setup
To run the project locally:
1. Clone this repo
2. `cd` into the project folder
3. Run `npm install` to install dependencies
4. Run `npm start` to launch the dev server

To build for production:
npm run build

## Tech Stack
- [Parcel](https://parceljs.org/) – bundler for building and running the app
- [Navigo](https://github.com/krasimir/navigo) – client-side router for SPA navigation
- [Axios](https://axios-http.com/) – HTTP client for API calls
- [Netlify](https://www.netlify.com/) – deployment and hosting
- JavaScript, HTML, and CSS
